```md
# PRD — LifeOps MVP

## Problem

Most productivity apps separate tasks, notes, goals, and habits. This creates fragmentation. Users cannot easily see whether their daily actions are aligned with their future identity.

## Solution

LifeOps connects future self, goals, habits, tasks, notes, planning, and weekly review into one AI-powered personal operating system.

## Target User

Initial target user:
A self-improvement focused builder, learner, creator, or professional who wants to organize life around long-term goals and identity.

## Core Promise

LifeOps helps the user operate life intentionally by connecting daily execution with future self.

## MVP Modules

### 1. Future Self

User can define:

- Future identity
- Life areas
- Vision statements
- Current gap

### 2. Goals

User can create goals linked to life areas.

Goal fields:

- Title
- Description
- Life area
- Status
- Priority
- Target date
- Progress

### 3. Habits

User can create habits linked to goals.

Habit fields:

- Name
- Frequency
- Linked goal
- Reminder time
- Streak
- Status

### 4. Tasks

User can create tasks linked to goals.

Task fields:

- Title
- Description
- Due date
- Priority
- Status
- Linked goal

### 5. Notes

User can create notes.

Note fields:

- Title
- Body
- Tags
- Linked goal/task/habit
- AI summary

### 6. Dashboard

Dashboard shows:

- Today’s tasks
- Today’s habits
- Active goals
- Future self reminder
- Weekly progress
- AI suggestion

### 7. AI Daily Planner

AI generates a suggested day plan using:

- Active goals
- Pending tasks
- Due dates
- Habits
- Future self profile

### 8. Weekly Review

AI summarizes:

- Completed tasks
- Habit consistency
- Goal progress
- Notes
- Wins
- Gaps
- Next week suggestions

## Success Criteria

MVP is successful if user can:

- Define future self
- Create goals
- Link habits to goals
- Track habit completion
- Manage tasks
- Add notes
- See dashboard
- Generate daily plan
- Generate weekly review

## Non-MVP

Do not build yet:

- Content Studio
- Media Library
- Publishing integrations
- Mobile app
- Browser extension
- Voice assistant
- Calendar integration
- WhatsApp integration
```
